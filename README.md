# 🎮 Meu Tetris

Oi! Eu sou o Victor Gabriel, tenho 17 anos e sou aluno do 2º ano do Instituto Federal (IF).

Esse projeto começou como uma ideia de fazer um Tetris usando programação e, com o tempo, acabou ficando bem maior do que eu imaginava.

## 📖 Como tudo começou

Quando comecei a fazer o Tetris, eu ainda estava aprendendo e testando várias coisas. A ideia inicial era simplesmente conseguir criar um jogo que funcionasse e que eu pudesse jogar.

Fui fazendo o projeto aos poucos, mexendo no HTML, CSS e JavaScript e tentando entender como cada parte do jogo funcionava.

No caminho, apareceram vários erros e coisas que não funcionavam como eu queria. Algumas partes precisei refazer e outras fui descobrindo conforme o projeto avançava.

Mesmo assim, continuei mexendo nele e adicionando novas ideias.

## 🚧 Como está atualmente

Hoje o Tetris já está bem mais desenvolvido do que quando comecei, mas ainda não considero que ele esteja pronto.

Ainda tenho bastante coisa que quero mudar, melhorar e adicionar. Por isso, provavelmente o projeto vai passar por várias atualizações daqui pra frente.

Quero ir melhorando o jogo aos poucos, até chegar em uma versão que realmente fique do jeito que eu imaginei.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 🎯 Por que estou fazendo esse projeto?

Além de querer criar meu próprio Tetris, estou usando esse projeto para aprender mais sobre programação e colocar em prática o que estou aprendendo.

Como ainda estou no 2º ano do IF, sei que tenho muita coisa para aprender, então esse projeto também faz parte desse processo.

## 🔄 O projeto continua...

Esse ainda não é o final.

Tenho várias ideias para as próximas versões e vou atualizando o projeto conforme conseguir implementar cada uma delas.

Se você chegou até aqui, obrigado por dar uma olhada no meu projeto! ❤️
